# Animated slides for Quarto, built by Claude

Describe an animated diagram in plain English, and Claude builds it as a slide in your Quarto presentation. The boxes appear, the arrows draw themselves, the code types out, all in step with your talk.

This repo holds a set of Claude Code skills that teach Claude how to do that. You do not need to know how the animations work, and you do not need to write any code.

## See it in action

[This demo deck](https://01a11786-65ac-4d12-0701-2bbce02574ad.share.connect.posit.cloud/), titled "Animation as code", is a Quarto presentation whose animations were built with these skills. Open it in a browser and step through the slides.

## Why animate your slides

A static diagram shows the audience everything at once. A complicated one, such as a data pipeline or an architecture with six moving parts, loses people before you reach the second box. You can build it up step by step with revealjs fragments, but you are limited to things appearing and disappearing.

An animation lets you control the order and pace of the story. You can show data flowing from a database into an app, highlight one line of code while you explain it, or make a logo paddle across the screen. The usual alternatives each cost you something:

- Screen recordings and GIFs are fuzzy when projected, cannot be paused on a point, and need re-recording for every change
- PowerPoint animations live in a binary file that cannot be diffed, reviewed or generated by a script
- Hand-written web animation needs you to learn a framework first

Canvas Commons animations sit in between. They are drawn from shapes and text rather than recorded, so lines stay sharp even when the animation zooms into a detail. They play in the browser inside your slide, and the source is plain text that lives in your project next to the rest of the deck.

## What is Canvas Commons?

[Canvas Commons](https://github.com/canvas-commons/canvas-commons) (formerly Motion Canvas) is a free, open-source library for making animations from code. Everything on screen is a shape, a line or a piece of text that the library redraws on every frame, so a camera move can zoom into a detail and the lines stay crisp. You write a short script that says what appears, moves and changes, and the library plays it back in a web page. It was designed for explainer videos, which is exactly the shape of a good slide: one idea, told in a sequence.

Quarto ships a web player for it, so an animation drops into a `revealjs` slide with one line:

```
{{< canvas-commons ./animations/src/my-scene.js fullscreen=true >}}
```

Writing those scripts is a developer skill. That is the gap these skills fill: Claude writes the script, builds it, drops it into your slide and checks how it looks. You describe, review and ask for changes.

## What you can ask Claude to do

Once the skills are installed, you can say things like:

- "Set up a new project for animated slides"
- "Add a scene that shows data flowing from three databases into one dashboard"
- "Turn the diagram in `architecture.drawio.svg` into an animation"
- "Show this R code with syntax colours, highlighting each step in turn"
- "Take a screenshot of the slide and check that the text fits"
- "Remove the smoke test slide"

The `seed/` folder holds worked examples of finished scenes and the diagrams they came from, so you can see what is possible. `seed/tour/` is the best place to start: ten short scenes, one per thing you can ask for.

## What you need

- [Positron](https://positron.posit.co), or any editor with a terminal, which also gives you Quarto
- [Claude Code](https://claude.com/claude-code), signed in
- [Node.js](https://nodejs.org) version 22, to build the animations
- `make`, which is already on macOS and Linux and comes with WSL on Windows
- `git`, only if you install by cloning the repo

These skills are tested on Linux (including WSL). They should work on macOS. They have not been tested on native Windows.

## Install

You do this once. There are two ways: as a Claude Code plugin, or by cloning the repo.

### As a plugin (recommended)

1. Open Positron, then open its terminal from the **Terminal** panel at the bottom
2. Start Claude Code by typing `claude`, then add the marketplace and install the plugin

   ```
   /plugin marketplace add andrie/quarto-canvas-commons-skill
   /plugin install canvas-commons@quarto-canvas-commons-skill
   ```

3. Start a new session so Claude picks up the skills. They appear as `/canvas-commons:motion-canvas-scene` and so on, and Claude uses them when your request matches

To update later, run `claude plugin marketplace update` and then `claude plugin update canvas-commons@quarto-canvas-commons-skill`, and start a new session. A project you made earlier keeps its old copy of the extension and Makefile rules, so open it in Claude Code and ask it to "upgrade this project's Canvas Commons setup". The plugin is versioned, so you get an update when the version number in `.claude-plugin/plugin.json` changes. To remove it, run `claude plugin uninstall canvas-commons`.

### By cloning the repo

Use this if you want to change the skills yourself.

1. Download this repo into a folder in your home directory, which needs `git`

   ```bash
   git clone https://github.com/andrie/quarto-canvas-commons-skill.git ~/quarto-canvas-commons-skill
   ```

2. Preview what the installer will do, then run it

   ```bash
   bash ~/quarto-canvas-commons-skill/scripts/install.sh --dry-run
   bash ~/quarto-canvas-commons-skill/scripts/install.sh
   ```

   The installer links each skill into `~/.claude/skills`, which is where Claude Code looks for them. It never overwrites a folder that is already there.

3. Start a new Claude Code session so it picks up the skills

To update later, run `git pull` inside `~/quarto-canvas-commons-skill`. Because the skills are links, the update takes effect straight away. A project you made earlier keeps its old copy of the extension and Makefile rules, so open it in Claude Code and ask it to "upgrade this project's Canvas Commons setup". It prints a plan first, applies the safe steps, and asks before it deletes anything. To remove the skills, run the installer with `--uninstall`, which deletes only the links it made.

## Make your first animated slide

1. In Positron, choose **File > New Folder**, make an empty folder for your talk and open it
2. Open the terminal and type `claude`
3. Type: `Set up a project for animated slides`

Claude asks for a name for your deck, copies in the project files, installs what it needs, builds a small test animation and renders the deck. That takes a few minutes the first time.

Then ask for your first real scene, for example "Add a scene that shows a request travelling from a browser to a server and back". Claude writes it, builds it, and adds it to `deck.qmd`. Run `make preview` to see the deck in your browser as you work.

Already have a Quarto deck? Open its folder and ask Claude to "add Canvas Commons animations to this project". Claude merges into your existing `Makefile`, `package.json` and `.gitignore` and does not overwrite anything.

## What is in the box

| Skill | What it does |
|---|---|
| `motion-canvas-scene` | Sets up a project, adds and removes scenes, checks that the build works, takes screenshots of a slide, and fixes build errors |
| `motion-canvas-authoring` | Layout, timing and style patterns for a good scene |
| `svg-to-motion-canvas` | Turns a draw.io or SVG diagram into an animation |
| `motion-canvas-review` | Finds repeated code in a scene that a shared component would remove |
| `motion-canvas-r-code` | Syntax colours and fonts for R and Python code on a slide |
| `motion-canvas-api` | A searchable cheat sheet for the Canvas Commons 0.4.0 API |
| `canvas-commons-library` | Shared styles, a database icon, a pulse effect and ready-made scenes |

You do not need to pick a skill. Claude chooses the right one from what you ask.

## Known limits

- The skills target Canvas Commons **0.4.0**. Newer versions may change the API
- The shortcode `width="50%"` does not take effect, and leaving out `auto` does not stop an animation playing on load
- The `seed/` scenes build, but nobody has played them all in a browser yet
- Taking a screenshot of a slide needs Playwright, which the script installs on request
